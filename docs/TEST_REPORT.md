## 13. 回归测试建议

每次上线前建议至少执行：

```bash
npm run lint
npm run build
curl -I http://52.37.190.58/
curl -I http://52.37.190.58/admin
curl -u admin:admin123 -I http://52.37.190.58/admin
curl -u admin:admin123 -I http://52.37.190.58/api/admin/posts
```

重点回归：

1. 首页不展示 admin 入口。
2. 后台未登录不可访问。
3. 后台导航选中状态正确。
4. 发布文章后前台可见。
5. 非发布状态文章前台不可见。
6. AWS 原地部署后 IP 不变化。

## 14. 测试结论

当前版本核心链路通过：前台访问、后台访问保护、文章内容管理系统、PostgreSQL 数据读写、AWS 线上部署和后台导航状态均已验证通过。

项目可以作为第一版内容管理型期刊网站继续使用。下一阶段建议优先完成页面内登录表单和富媒体富文本能力，因为这两项已经进入明确产品需求，并会直接影响后台使用体验。
